# Portfolio Roadmap

## Phase 1 — Current Front-End Demo

- Static HTML/CSS/JavaScript
- Local browser storage
- PHQ-9 scoring
- PDF export
- Mission statement page

## Phase 2 — React Upgrade

- Convert UI to React components
- Use React Router
- Add persistent session state
- Add reusable question and result components
- Improve layout and accessibility

## Phase 3 — Backend API

- Node.js + Express API
- Register/login endpoints
- Password hashing with bcrypt/Argon2
- JWT authentication
- Assessment submission endpoint
- Assessment history endpoint
- Server-side PDF generation

## Phase 4 — Database

- MongoDB or PostgreSQL
- Users collection/table
- Assessments collection/table
- Audit log table
- Encrypted sensitive fields

## Phase 5 — Professional Features

- User dashboard
- Assessment history
- Score trend chart
- Clinician-facing view
- Export history
- Dark/light mode
- Testing suite
- OpenAPI documentation

## Phase 6 — Deployment

- Frontend on Vercel or Netlify
- Backend on Render/Railway/Fly.io
- Database on MongoDB Atlas/Supabase/Neon
- Environment variables
- Production logging
